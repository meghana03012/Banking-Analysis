# Banking Analytics Project | SQL & Power BI

## Project Overview

This project focuses on analyzing banking data to understand customer behavior, loan portfolio performance, repayment patterns, and debit and credit card transactions.

The main objective is to help banking teams make data-driven decisions related to lending, customer engagement, risk management, repayment monitoring, and cross-selling banking products.

The project covers the end-to-end data analytics lifecycle, from understanding business requirements and preparing data to performing SQL analysis and developing interactive Power BI dashboards.

## Business Objectives

- Analyze loan distribution, funded amounts, interest income, and repayment performance.
- Identify default loans, delinquent customers, and potential credit risks.
- Understand debit and credit card transaction trends and spending behavior.
- Compare loan and transaction performance across regions, branches, and customer segments.
- Support customer engagement and targeted marketing decisions.

## Tools and Technologies

- **SQL / MySQL:** Data querying, transformation, and business analysis.
- **Microsoft Excel:** Data inspection and preliminary validation, where applicable.
- **Power BI:** Interactive dashboards and data visualization.
- **DAX:** KPI calculations and business measures.
- **Data Modeling:** Relationships between customer, date, loan, and transaction data.

## Project Workflow

1. **Business Understanding:** Identified the business objectives, key questions, and performance indicators.
2. **Data Understanding:** Reviewed customer information, loan details, and debit and credit card transaction datasets. Identified the dataset grain, primary keys, and relationships.
3. **Data Cleaning:** Checked duplicate records, missing values, inconsistent categories, date formats, data types, and invalid transaction amounts.
4. **SQL Analysis:** Analyzed loan performance, repayment behavior, card transaction activity, customer segments, and regional performance.
5. **Data Modeling:** Connected relevant dimension and fact tables to support consistent reporting.
6. **DAX Calculations:** Developed measures for key business KPIs.
7. **Dashboard Development:** Created interactive Power BI reports with KPI cards, charts, and slicers.
8. **Business Insights:** Used the results to identify areas for improved customer engagement, lending decisions, and risk monitoring.

## Dashboard Features

### 1. Executive Overview
- Total funded loan amount
- Total loan count and interest income
- Principal recovery and repayment indicators
- Default and delinquency rates
- Loan and transaction performance trends

### 2. Loan Analytics
- Loan distribution by grade and purpose
- Loan performance by state, branch, or region
- Loan status distribution
- Repayment behavior and default analysis
- Monthly and yearly loan disbursement trends

### 3. Debit and Credit Card Analytics
- Total transaction amount
- Credit and debit transaction values
- Monthly transaction trends
- Transaction method distribution
- Branch-wise transaction activity
- High-risk transaction indicators and suspicious transaction patterns

## Key Business Insights

The dashboards are designed to help identify:

- Customer segments that may be suitable for targeted product recommendations.
- Regions and branches with comparatively high loan or transaction activity.
- Loan grades and customer segments requiring closer repayment and risk monitoring.
- Seasonal or monthly changes in transaction and loan disbursement activity.
- Opportunities to improve engagement with inactive card customers.

Specific findings should be validated against the underlying datasets and selected dashboard filters.

## Business Recommendations

- Introduce targeted cross-selling campaigns for relevant customer segments.
- Monitor high-risk loans and overdue repayments for early intervention.
- Improve engagement with inactive debit and credit card customers.
- Use transaction trends to plan relevant marketing campaigns.
- Track regional performance and investigate significant changes in loan or transaction activity.

## How to Use This Project

1. Review the dashboard screenshots in the `images/` folder.
2. Open the SQL scripts to understand the analysis queries.
3. Open the `.pbix` file in Microsoft Power BI Desktop, if included.
4. Connect the report to the appropriate authorized dataset if the original data is not included.
5. Explore the dashboard using its filters and slicers.

## Data Privacy

Only share datasets that you own or have permission to publish. Customer names, account numbers, card details, personal information, and confidential banking records must not be uploaded. Use anonymized or synthetic data when necessary.

## Conclusion

This project demonstrates how SQL and Power BI can be used to transform banking data into interactive reports and actionable business insights. It showcases practical skills in data preparation, analytical querying, KPI development, visualization, and business problem-solving.
